# meetrec

Minimal cross-platform voice recorder. Captures the microphone and writes
mono MP3 files at **32 kbps / 16 kHz / CBR**, suitable for long meetings.

Single binary, Rust + Dioxus UI. Works on macOS, Windows, Linux.

## Install & run

Requires [mise](https://mise.jdx.dev/).

```sh
mise install
mise run dev
```

The first run will install Rust, `cargo-bundle`, `dioxus-cli` and fetch deps.

### Linux build deps

```sh
sudo apt install libasound2-dev libwebkit2gtk-4.1-dev libgtk-3-dev \
                 libxdo-dev pkg-config build-essential
```

### Windows

Requires WebView2 runtime (preinstalled on Win11; Win10 may need
[Evergreen Bootstrapper](https://developer.microsoft.com/microsoft-edge/webview2/)).

### macOS

The first launch will prompt for microphone permission.

## Output

Files are written as `meeting_YYYYMMDD_HHMMSS.mp3` in the selected folder.
Verify a file with:

```sh
ffprobe -v error -show_streams meeting_*.mp3
# expect: codec_name=mp3, sample_rate=16000, channels=1, bit_rate=32000
```

## Build artifacts

```sh
mise run bundle
```

Produces portable bundles — no installer, just download and run:

- **macOS**: `meetrec.app` (universal2, x86_64 + aarch64). The `.app`
  bundle is required for the microphone permission prompt
  (`NSMicrophoneUsageDescription` lives in `Info.plist`).
- **Windows**: `meetrec.exe` — single portable executable. Depends on
  the WebView2 runtime (preinstalled on Win11 and recent Win10).
- **Linux**: `meetrec.AppImage` — single-file portable, runs on
  Ubuntu / Arch / Fedora / Debian / openSUSE etc. with no system
  packages required. webkit2gtk-4.1, GTK 3 and libasound are bundled
  inside.

To launch the Linux build:

```sh
chmod +x meetrec-linux-x86_64.AppImage
./meetrec-linux-x86_64.AppImage
```

On systems without FUSE you can extract and run:

```sh
./meetrec-linux-x86_64.AppImage --appimage-extract
./squashfs-root/AppRun
```

## Config

All user data lives in a single directory alongside `config.toml`:

| Platform | Path |
|----------|------|
| macOS    | `~/Library/Application Support/meetrec/` |
| Windows  | `%APPDATA%\meetrec\` |
| Linux    | `~/.config/meetrec/` |

Files in this directory:

| File | Description |
|------|-------------|
| `config.toml` | Persistent settings (API keys, model, audio output folder, UI state) |
| `meetrec.log` | Latest run log (rotated to `meetrec.log.1` at 5 MB) |

**Migration:** if an old `…/geoffroy/meetrec/` directory exists from a previous version, meetrec moves it to the new path on first launch.

## Input device diagnostic

A fresh dump of every input device cpal enumerated (with its id, name,
manufacturer, interface, direction…) is written to `devices.txt` next
to `config.toml` on each launch. Useful when an expected microphone is
missing from the dropdown.

## Icon

A placeholder icon is generated by `scripts/make_icon.ps1` (Windows) or
`scripts/make_icon.sh` (mac/linux). Replace `assets/icon.png` with your own
1024×1024 transparent PNG for production.

## Release

Push a `v*` tag — `.github/workflows/release.yml` builds artifacts for the
three platforms in a matrix and attaches them to a GitHub Release.
